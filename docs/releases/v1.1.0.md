# v1.1.0

`-q` now reads as well as finds.

## Added

**Read one topic out of a session.** A query used to only pick a session out of a listing. On a session you have already chosen, it keeps just the exchanges about your topic — each match with the turn around it, so a matched answer arrives with the question that produced it.

```bash
catchup codex/3 -q "deploy"
```

**Listings quote what matched.** The title column becomes `MATCH` and carries a literal passage from the session, so you can tell the one you want from the four others mentioning the same word.

## Faster

**Listings skip sessions before parsing them**, deciding from raw bytes on disk. Results are unchanged.

| | before | after |
| --- | --- | --- |
| search every agent, no match | 5.6s, 1.35GB | 2.5s, 636MB |
| list a directory with no sessions | 3.5s | 1.7s |

## Fixed

- **`--since-compact` no longer drops context the agent itself kept.** Pi's retained tail and Codex's retained user turns fell outside the single cut applied to every agent; each agent now describes its own compaction shape.
- **A session still being written reads as a torn tail, not malformed JSON.** Parsers also report record types they don't recognize instead of passing over them.

## Also

**Opt-in [quota reminder](https://github.com/wilbeibi/catchup/blob/main/recipes/quota-visibility.md) for Claude Code and Codex.** Your remaining five-hour and weekly quota in the statusline, so you choose when to hand off instead of finding the limit mid-task.

## Install

```bash
brew upgrade catchup            # or: brew install wilbeibi/tap/catchup
curl -fsSL https://catchup.pages.dev/install.sh | sh
go install github.com/wilbeibi/catchup@latest
```
