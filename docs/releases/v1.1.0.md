# v1.1.0

Find the part of an old session you need, without reading the whole thing.

## Search inside a session

`-q` can now do more than find a session. Add it after a specific session to show
only the exchanges that mention your search term, with enough surrounding context
to understand the answer.

```bash
catchup codex/3 -q "deploy"  # show deployment-related exchanges in session 3
```

Search results also show a short quote containing the match. You can tell which
session is relevant before opening it.

## Faster searches and empty listings

Catchup now skips sessions that cannot match before fully reading them. Search
results are the same, but broad searches and directories with no sessions finish
faster and use less memory.

| | before | after |
| --- | --- | --- |
| search every agent with no match | 5.6s, 1.35GB | 2.5s, 636MB |
| list a directory with no sessions | 3.5s | 1.7s |

## Fixed

- **`--since-compact` keeps the context your agent kept.** This fixes missing
  retained messages in Pi Agent and Codex sessions.
- **Read sessions that an agent is still writing.** Catchup keeps
  the complete records and tells you when the final record is incomplete. It
  also warns about new record types it does not yet understand.

## Also

Set up [quota visibility](https://github.com/wilbeibi/catchup/blob/main/recipes/quota-visibility.md)
to see Claude Code or Codex quota in the statusline. Codex users can also opt
into a desktop reminder near the limit. That gives you time to hand off before
the quota runs out.
