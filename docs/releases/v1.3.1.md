# v1.3.1

OpenCode 2.x sessions are readable again.

## Fixed

- **`opencode` finds sessions on OpenCode 2.x.** OpenCode 2.x moved its history into new tables, so catchup reported "no sessions found" even with plenty of history. It now reads the 2.x tables, including sessions OpenCode migrated from 1.x, and still reads 1.x databases as before. Compaction summaries and failed tool calls appear as they did on 1.x. Thanks @jiz4oh for the report (#26).

## Install

```bash
brew upgrade catchup            # or: brew install wilbeibi/tap/catchup
curl -fsSL https://catchup.pages.dev/install.sh | sh
go install github.com/wilbeibi/catchup@latest
```
