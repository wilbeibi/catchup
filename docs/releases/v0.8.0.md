## Added

catchup now reads **GitHub Copilot CLI** sessions.

```bash
catchup copilot                     # recap the newest Copilot session here
catchup fork copilot                # pick the work back up in Copilot
catchup fork copilot --into codex   # or hand it to another agent
catchup fork claude --into copilot  # or hand another agent's session to Copilot
```

Both handoff directions are native: Copilot resumes its own session, and it
takes a seeded prompt from anyone else. Running catchup from inside a Copilot
session picks up that session rather than guessing by recency.

Thanks to @jaderocks for asking for it (#8).
