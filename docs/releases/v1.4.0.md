# v1.4.0

Hand a Devin web session to a local agent, and read complete Antigravity transcripts.

## Devin web sessions

`fork --from` now accepts a Devin session URL:

```bash
export DEVIN_API_KEY='your-api-key'
catchup fork --into codex --from 'https://app.devin.ai/sessions/YOUR_SESSION_ID'
```

Use an organization-scoped service-user key from Devin's **Settings > Devin API**,
with read access to the session. Enterprise URLs (`*.devinenterprise.com`) work
too. catchup imports the conversation and failed shell commands, sends the key
only to `api.devin.ai`, and does not store it.

The importer uses Devin's `v3beta1` event endpoint, which is not in the public
v3 specification and may change. Attachments, non-shell tool failures, and
compaction history are unavailable. Personal access tokens and enterprise-scoped
keys are not supported.

## Antigravity

Verified against agy 1.5.14.

- **Full prompts and replies.** agy truncates long messages in
  `transcript.jsonl`; catchup now merges it with `transcript_full.jsonl`.
  Steps missing from either file, or replayed by compaction, appear once and
  in order.
- **Titles and sessions from agy's own database.** Native titles come from
  `conversation_summaries.db` and are searchable with `-q`. Headless (`-p`) and
  `/plan` sessions now appear, slash commands such as `/model` no longer become
  titles, and subagents stay out of listings but remain readable with `--id`.
- **Failures and tool calls.** API errors such as 429s show as stop events,
  failed tool steps as failures, and tool calls with `--show tools`.
- **The current session.** Inside an agy shell, catchup reads the conversation
  you are in, not just the newest one in the directory.

Stores without the database or `transcript_full.jsonl` read as before.

## Fixed

- `fork -q` with several matches keeps each session's directory, and keeps
  `--all-dirs` in the suggested command.
- HTML output shows failed tool inputs when `--show tools` is set.
- SQLite paths containing `%`, `?`, or `#` open correctly.

`go install` now needs Go 1.26 or newer.
