## Added

catchup now reads **ZCode** (Z.ai) and **DeepSeek Harness** (`dsh`) sessions.

```bash
catchup deepseek                 # recap the newest dsh session here
catchup zcode --list             # find an older one
catchup fork deepseek            # pick the work back up in dsh
catchup fork zcode --into claude # continue ZCode work in Claude
```

`fork deepseek` resumes through dsh's own profile launcher, so the session
keeps its native state — the same trade `fork claude` and `fork codex` make.

Both providers are @aceHubert's work, and catchup's first outside
contribution. Thank you.

brew upgrade catchup            # or: brew install wilbeibi/tap/catchup
