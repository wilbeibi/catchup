## Added

`--version` now tells you when a newer release exists. Installing once
gave you no way to find out — Homebrew mentions it at upgrade time, but
the curl installer and `go install` leave a binary that never speaks up.
The check is quiet on purpose: it runs only in an interactive terminal,
prints to stderr, skips unstamped builds, and fails silently when
offline. Opt out with `CATCHUP_NO_UPDATE_CHECK`.

## Fixed

- Pi's `/tree` branch summaries now stay on the timeline. When a session
  gives up one branch for another, Pi records why at the fork — "tried
  A, dropped it for B" — and catchup was throwing that away as
  bookkeeping. It now reads as its own entry, so a recap carries the
  explanation the agent was still working from.
- `--since-compact` warns when it cuts at a compaction marker that kept
  no summary (Codex and OpenCode log a bare marker). The tail used to
  look complete with no sign a briefing was lost; it now says so and
  points back at `--last N`, and the skill gives the agent the same
  instruction.

## Install

The one-line installer now serves from `catchup.pages.dev` instead of
`raw.githubusercontent.com`, which is blocked on some corporate networks
and in China:

```bash
curl -fsSL https://catchup.pages.dev/install.sh | sh
# or
brew install wilbeibi/tap/catchup
# or
go install github.com/wilbeibi/catchup@latest
```
