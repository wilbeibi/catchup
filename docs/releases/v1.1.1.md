# v1.1.1

Handoffs show what you said, in the session you started.

## Fixed

- **A Claude Code session stays where you started it.** If a session moved into
  a subdirectory or a worktree, it used to drop out of the listing for the
  directory it began in. It now stays listed there.
- **Claude Code's own notices no longer appear as your messages.** Claude Code
  saves background-task reports, local command output and injected reminders
  as user messages. Catchup used to show them as things you said, count them
  against `--last N`, and match them in searches. A message that contains
  nothing but these notices is now skipped. Your slash commands and `!` lines
  are kept, and so is any message that also says something of its own.
- **Session text can't take over your terminal.** Tool output saved in a
  session can hold color codes, window-title changes or clipboard writes.
  Catchup used to print them as-is and now removes them from session lists,
  transcripts and handoffs. JSON output is unchanged.
- **The skill upgrade warning appears only when the skill changed.** A release
  whose `SKILL.md` was identical still told you to re-run
  `catchup install-skill`. The warning now also checks whether the skill text
  itself changed.

## Install

```bash
brew upgrade catchup            # or: brew install wilbeibi/tap/catchup
curl -fsSL https://catchup.pages.dev/install.sh | sh
go install github.com/wilbeibi/catchup@latest
```
