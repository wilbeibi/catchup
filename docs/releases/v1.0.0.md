# v1.0.0 🎉

Windows is now a first-class, tested release platform.

## Added

Download a Windows release ZIP and use `fork --into`, `--dir`, and `--from`
with native paths and shells.

Agent handoffs now retain source-recorded failed calls and results, so the next
agent can see known dead ends. Human Markdown and HTML stay conversation-only;
JSON includes the structured failure entries.

## Fixed

- Windows `fork --into` now passes a file path, so multi-line handoffs arrive
  intact instead of truncating in `.cmd` shims.
- Windows path matching handles drive letters, separators, and case; relative
  `--dir` values resolve correctly on every platform.
- `fork` returns the launched agent's exit status, including the conventional
  signal status of 128 plus the signal number.
- `--from` removes URL credentials before a label reaches an error or receiving
  session; Windows source labels preserve literal percent signs.

## Install

```bash
brew upgrade catchup            # or: brew install wilbeibi/tap/catchup
curl -fsSL https://catchup.pages.dev/install.sh | sh
go install github.com/wilbeibi/catchup@latest
```

Windows binaries are on the [releases page](https://github.com/wilbeibi/catchup/releases).
