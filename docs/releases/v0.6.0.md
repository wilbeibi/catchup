## Changed
- `catchup --list` answers "where was I" across every agent, not just
  whichever one happened to be newest in the directory. More than one
  agent works in a directory — that is the premise of the tool
- The listing shows the handle you actually type back (`claude/3`) and
  how long ago the session was, and gives the space back to TITLE.
  Sessions the agent never named used to all read as the directory name;
  they now show their opening message, which is what tells them apart.
  The session id moved to `--json`, where the scripts that want it live
- `fork` names the session it picked on stderr before launching. It acts
  on an inferred source and it is the one command that spends money on
  the guess — now you can interrupt a wrong one while the transcript is
  still being read
- `fork <agent> --into <same agent>` is allowed with `--last` or
  `--since-compact`: a reseed rather than a resume, shedding a spent
  context and keeping the work. Bare same-agent `--into` is still
  refused, and now names both exits

## Fixed
- Codex sessions that stacked context envelopes in one user turn — a
  plugin catalog followed by an AGENTS.md preamble — had that machinery
  read as conversation. Every recap of such a session opened with it,
  and every cross-agent fork seeded the next agent with your global
  AGENTS.md. Envelopes are now stripped one at a time, and the turn
  counts as injected only when nothing a person wrote is left
