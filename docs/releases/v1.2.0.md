# v1.2.0

Find the session that ran a command, wherever you started it.

## Grok Build and Amp

catchup now reads **Grok Build** sessions, and you can continue them in either
direction.

```bash
catchup grok                     # recap the newest Grok session here
catchup fork grok                # pick it back up in Grok
catchup fork claude --into grok  # hand Claude's work to Grok
```

For `/loop` and cron prompts, catchup shows what you typed, not the instruction
Grok generated from it.

Grok Build support is @rudironsoni's work (#23), and their first contribution.
Thank you.

catchup also reads **Amp** conversations cached on your machine. Cloud-only
threads appear once Amp caches them locally, and tool results and reasoning are
left out. Amp can supply a handoff but can't be launched as an `--into` target.

## Which session ran that command

```bash
catchup claude --show tools                 # the agent's tool calls, in place
catchup codex --show tools -q "rm -rf"      # which session ran it
```

`--show tools` lists each tool call a Claude Code or Codex session made, after
the text that introduced it. With `-q`, the search also matches the command or
input of each call. Without the flag, output is unchanged.

## Sessions from other directories

`--all-dirs` searches sessions from every directory, so you can find the
session you remember even if you started it in another checkout. Listings now
show Codex's own session titles, and show when one session is a fork or
subagent of another (#22).

## Fixed

- **DeepSeek Harness sessions show their latest turns.** dsh 0.1.5 and later
  copy an older session into a new log when they write to it. catchup used to
  read the old copy and miss the newest turns. It now reads the newest log, and
  sessions that exist only in the newer format open. Subagent sessions no
  longer crowd the listing; `--id` still opens them. dsh no longer has a
  terminal UI, so `catchup fork deepseek` now says to use Fork in the dsh web
  UI, or `--into <agent>`, instead of starting a command that fails.
- **Codex interrupt notices no longer appear as your messages.**
- **Claude API errors no longer read as the agent's answer.** They show as the
  point where the session stopped.
- **Missing stores aren't errors.** If OpenCode or ZCode isn't installed,
  listings treat it as having no sessions. A cross-agent `--json` listing with
  no sessions prints `[]`.

Transcripts for people now show times in your local timezone. JSON output stays
in UTC.
